# Analyse du Design - Dehbi Voyages

## Palette de Couleurs
- **Bleu Principal**: #0052CC (boutons, accents)
- **Bleu Clair**: #0066FF (boutons secondaires)
- **Bleu Foncé**: #1F3A93 (barre de statistiques)
- **Orange**: #FF6B35 (boutons des destinations internationales)
- **Blanc**: #FFFFFF (arrière-plan, texte clair)
- **Gris Foncé**: #1A1A1A (texte principal)
- **Gris Clair**: #666666 (texte secondaire)

## Typographie
- **Titres**: Serif (style classique, élégant) - Police: Playfair Display ou similaire
- **Corps de texte**: Sans-serif (lisible) - Police: Poppins ou similaire
- **Poids**: Bold pour les titres, Regular pour le corps

## Sections Principales
1. **En-tête (Header)**: Logo + Navigation + Bouton Réserver
2. **Hero**: Image de fond (Tanger/côte) + Titre + Sous-titre + Boutons CTA
3. **Statistiques**: Barre bleue avec 4 statistiques
4. **Voyages Spirituels**: 3 cartes avec bordures bleues
5. **Destinations Marocaines**: 4 cartes avec images
6. **Destinations Internationales**: 6 cartes avec icônes + boutons orange
7. **Services Premium**: 3 cartes avec icônes
8. **Pied de page**: Logo + Liens + Formulaire contact

## Éléments de Design
- **Cartes**: Bordures arrondies, ombre subtile
- **Boutons**: Arrondis, transitions fluides
- **Espacements**: Généreux, hiérarchique
- **Images**: Overlay dégradé bleu sur les images de destination
